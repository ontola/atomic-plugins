The optional `syncables` CLI tests device login and read-only API access
through Local Thought, saves replication destination definitions, and records
reads in a separate local PostgreSQL archive. The `syncables/postgres` entry
provides owner-scoped compressed payloads, caching and offline recorded-run
replay. Runtime replication, durable outgoing changes and daemon installation
remain unimplemented. Existing Node and browser library imports are unchanged.
