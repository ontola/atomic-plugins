## Verification and its limits

At #360, all **48 collection tests across 57 reviewed OADs** passed, along
with the **481 revision-file pin checks** and the PR's required CI checks.
Every newly published overlay and both pre-existing default catalogs were
compared byte-for-byte with the checkout after its batch merged. The evidence
records historical checks, not a continuing uptime monitor.

The tests check composition, explicit operation scope, request paging fields,
response continuation fields and item envelopes against the pinned documents.
They do not establish live provider certification. No live credentials,
provider reads, package release or proxy deployment were part of this milestone.

Known source-document defects remain explicit in the tests: Mailchimp's
boolean default on a string schema, HubDB's missing `HubDbTableRowV3Wrapper`,
and Square's missing `AppFeeAllocation`/`CurrencyExchange` references. The
pin validator also reports pre-existing unparsable Codat, Bunq and SendGrid
documents ([#307](https://github.com/ontola/atomic-plugins/issues/307)).
Passing checks do not mean every upstream OAD validates as OpenAPI.

## Where a future task can start

   `APIs/twilio.com/api/1.55.0/openapi.yaml` at
   `fdc294bd8f2520f4cef3491726d86b603b5cf946`. Its 61 candidate GET collections
   return relative `next_page_uri` values. Pagination Schemes 0.3.0's
   `nextLink` requires a full URL. Specify relative-link resolution in

   implement and test consumer support, then publish a new immutable overlay.
   The trial draft was removed; the old published overlay remains.

   suggest pagination, but the OAD omits request paging parameters. Fetching
   the official reference was unsuccessful during review. Verify input names,
   defaults and termination with official documentation before specifying and
   testing any necessary schema enrichment. No draft was committed.
3. **Authentication, CRUD and live use.** Additional metadata, consumer support,

## Rules to preserve

Provider paths mirror `openapi-directory`. Each overlay's filename and standard
`extends` pin the full commit that last changed its OAD. Keep published revision
files and dated catalogs immutable; add a new kind/revision or dated catalog
for changed behavior. Keep the root `.nojekyll` for byte-preserving Pages
publication. The legacy `overlays/catalog.json` was already removed after the
verified October 2 live switch; it must not be restored as part of this handoff.

The authoritative extension specifications are in `openapi-extensions/`,
migrated from `pondersource/openapi-extensions`; `overlays/spec/` contains an
older Pagination Schemes copy. A new pagination mechanism belongs in the
authoritative specification before an overlay implements it.

The repository's [Keep going rule](../AGENTS.md#keep-going) carries authorized
work through checks and PR completion. An explicit pause or stop takes
precedence. The completed provider milestone and its remaining gaps were
reported on [the coordination board](https://github.com/ontola/atomic-plugins/issues/227#issuecomment-6054775743).
