# Pieces: views, integrations and lenses on typed resources

Status: **target, not a plan of record. Nothing here is implemented beyond the
prototype named below.** It writes down Michiel's long-term target for plugins
(2026-10-08), what is already decided towards it, and what is missing. Whether
it replaces [`bundles.md`](bundles.md) is open (Decision Inbox Q-100, §4).

Every claim is marked **checked** (with its source) or **estimated**. Sources
were read on 2026-10-08 at atomic-plugins `5e7cf25` (`origin/main`), the
atomic-server pin `a12b74a` (candidate19, [`.atomic-server-ref`](../../.atomic-server-ref))
and the head of
[ontola/atomic-server#2069](https://github.com/ontola/atomic-server/pull/2069),
`bab52555`. Sizes are always estimated.

Michiel's statement (2026-10-08, relayed by the coordinator), verbatim:

> "On a resource with a type, or a table with a type and a row type, the following should be available:
>
> - views from the atomic-plugins catalog whose manifest announces that they match the (row) type;
> - integrations from the localthought.io catalog that produce the appropriate schema for the table;
> - Devonian lenses from the atomic-plugins catalog that can be combined with integrations from the localthought.io catalog."

## 1. The target, in short

### 1.1 The three pieces

The target, restated from the statement and §1.2; it describes no current
state, so its rows carry no marks. §2 and §3 compare it with today.

| Piece           | What it is                                                                                                                                        | Comes from                                                                                                                                                                                                                          | Declares                                                                          | Needs from the host                                                                                                                                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **View**        | A module that shows (and, with a grant, edits) a table of a row class, or one resource of a class                                                 | The atomic-plugins catalog, [`integrations/catalog.json`](../../integrations/catalog.json), published on GitHub Pages                                                                                                               | The (row) classes it matches, by exact subject                                    | An offer by exact class match (Q-087); the iframe and `store` API of a drive app; the "Allow editing" row grant                                                                                                              |
| **Integration** | A platform that syncs a table with a provider: an OpenAPI document plus overlays, read and written by syncables, with no per-provider plugin code | The proxy's catalog: a dated catalog under [`overlays/catalog/`](../../overlays/catalog/), composed and served by `integration-proxy` (localthought.io runs `2026-10-02.json`; checked, [`AGENTS.md`](../../AGENTS.md) "overlays/") | The row class each synced collection produces (not declared anywhere today, §3.2) | An offer under **Connect** (Q-092) on an exact match or through at most 2 two-way lenses (Q-087, Q-091); one sync binding per integration per table (Q-090); a place to run syncables; a proxy connection; a sync-state view |
| **Lens**        | A declarative, two-way mapping between two row classes                                                                                            | A lens catalog next to the ontology in atomic-plugins, plus drive-local lenses that need review (Q-089)                                                                                                                             | Source class, target class, field mapping                                         | Live translation of a table's rows for an integration (Q-088); trust (catalog, or an approved drive-local lens); the chain search                                                                                            |
