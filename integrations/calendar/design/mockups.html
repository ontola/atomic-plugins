Calendar plugin — screens and states

Static mockups for integrations/calendar/design/DESIGN.md (issue #89). Section numbers match the design doc. Sample data is invented: week of Monday 21 September 2026, "now" is Thursday 24 September 14:20, viewer in Amsterdam (GMT+2). Frame widths are the plugin iframe's width.

Colours come only from --pl-* tokens (host --t-* with fallbacks).Calendar swatches are Google's calendar colours.Page follows your system theme; 5.7 and 5.8 also show both themes side by side.

5.1No proxy

Host has no store.proxy. Nothing is fetched; no button, because the user cannot fix this from here.

Calendars can't be reached from this server yet

This Atomic Server can't reach calendar providers on your behalf, so nothing was fetched. Ask the server's administrator to enable the integration proxy.
